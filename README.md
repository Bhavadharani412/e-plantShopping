# e-plantShopping

## Paradise Nursery - Online Plant Shopping Application

### Project Overview

e-plantShopping is a React-based online plant shopping application developed for Paradise Nursery. It allows users to explore different varieties of houseplants, browse products by category, and manage their selected plants through an interactive shopping cart.

### Features

- Browse different varieties of houseplants.
- View plant images, names, descriptions, and prices.
- Explore plants organized into categories.
- Add plants to the shopping cart.
- Manage cart quantities.
- View individual product subtotals and the overall cart total.
- Remove products from the cart.
- Continue shopping or proceed to checkout.

### Technologies Used

- React.js
- JavaScript
- Redux Toolkit
- React Redux
- CSS
- Git and GitHub

### Repository Name

e-plantShopping

### Project Objective

To develop an interactive plant shopping application using React and Redux, demonstrating component-based architecture, state management, dynamic rendering, and shopping cart functionality.
